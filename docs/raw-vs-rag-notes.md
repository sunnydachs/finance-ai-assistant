# メモ: 素のモデル vs RAG 比較（Week 2 実測）

- 日付: 2026-09-14（初回構築時の実測）
- 条件: 同一質問を `--raw`（コーパス検索なし）と RAG（文字 n-gram BM25, top-4）で実行。
- モデル: `inclusionai/ling-3.0-flash-fin:free`（OpenRouter 経由、無償枠）
- この比較の目的: RAG なしで架空の銀行の質問に答えると何が起きるかを、eval の外側で定性的に記録しておく。

## 観察 1: 素のモデルは「知らない銀行」について一般論で答える

質問: 「外貨預金の為替手数料を教えてください。」

- **RAG**: 米ドル25銭 / ユーロ40銭 / 豪ドル70銭（片道）、往復2回分と明記、出典 [FAQ-034]。**コーパスの数値と一致。**
- **素のモデル**: 「1ドル約150円の場合、買値が149.5円…」「外貨両替は1通貨あたり1〜3円程度」など**一般論・それらしい相場観**を生成。みどり銀行（架空）の事実は持ち合わせていないため、顧客向け回答としては**ハルシネーション同然**の説明になる。

## 観察 2: 手続き質問でも素のモデルは汎用知識に置き換える

質問: 「変額年金を途中で解約した場合はどうなりますか？」

- **RAG**: 「解約払戻金は払込保険料を下回ることがある。変額年金は特に運用実績により下回る可能性がある」と**FAQ-040 の文言に忠実**に回答し、[FAQ-040][FAQ-037] を出典付け。
- **素のモデル**: 「解約控除や手数料がかかる。特に契約初期（5年程度以内）は解約費用が高くなる傾向」など**当行では保証できない一般論**。当行の商品設計（FAQ-040）と矛盾する可能性を自分では検出できない。

## 観察 3: 素のモデルでは「みどり銀行」自体が存在しない

「『みどり銀行』という銀行について知っていることを教えて」に対し、素のモデルは「正式名称の銀行は現在存在しないようです」と正しく答える。つまり**当行に関する質問に答える材料が最初から無く**、RAG の存在意義（コーパス注入）が最も端的に示される。

## 教訓（設計への反映）

1. **検索は問題を半分にする**: 検索が正しい資料を top-1 で当てられれば、回答の正確性は資料の文言に引き寄せられる。残る問題は「検索が外れたとき」なので、eval では検索成否を分離して測る（cite カテゴリ）。
2. **出典强制が検証可能性を作る**: 出典 ID を文末に必須化したことで、回答の裏付けを文字列マッチで自動判定できる。これは eval を機械可判にする前提条件。
3. **素のモード（`--raw`）は資産**: デモと README の「なぜ RAG か」の証拠として残す。eval スイートにも raw モードを比較対象として残す価値がある（将来拡張）。
